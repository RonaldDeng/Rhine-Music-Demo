Rhine Music Demo · V0.3.0 · Windows 版
=====================================

把本地音乐放进三维专辑架，在浏览器里浏览和播放。
适用于 Windows 10 及更新版本（含 Windows 11），64 位。无需安装 Node.js，运行环境已放在 runtime 文件夹内。

一、开始使用
------------
1. 把压缩包完整解压（不要在压缩软件里直接双击运行）。得到 V0.3.0 文件夹。
2. 双击 “Rhine Music.exe”。几秒钟后默认浏览器会打开播放器。
   也可以双击 “启动音乐播放器.bat”，效果相同，但会显示一个黑色窗口，方便排查问题。
3. 点击页面里的“音乐库”，填写音乐文件夹的完整路径，每行一个，例如：
       D:\音乐
       C:\Users\你的用户名\Music
       \\NAS\music
   在资源管理器中选中文件夹，按住 Shift 右键“复制为路径”，直接粘贴也可以（带引号没关系）。
   点“保存目录并扫描”，完成后专辑会自动出现。
4. 以后再次双击 Rhine Music.exe 即可。已经在运行的服务会直接复用，不会重复启动。

没有音乐时，可以点“先查看演示封面”体验界面。

二、数据、日志和隐私
--------------------
- 索引、封面缓存、配置和日志保存在解压目录旁边的 music-data-v3 文件夹
  （即 V0.3.0 文件夹的上一级目录），日志文件是 player-service.log。
- 歌曲始终从原位置读取，不会被复制、移动或修改标签。
- 服务只监听本机 127.0.0.1，局域网内的其他设备无法访问。
- 请不要把 music-data-v3 放在只读目录；放在 OneDrive 等同步目录中可能变慢。
- 主题、画质、音量等偏好保存在浏览器里；换浏览器或换端口后需要重新设置。

三、升级
--------
先退出旧版本的服务（见下文“如何退出”），再把新版本解压到旧版本所在的同一个文件夹中，
继续使用旁边的 music-data-v3，就会保留原有的索引和设置。

四、如何退出
------------
播放器在后台运行，关闭浏览器标签页不会停止它，这样下次打开更快。
需要完全退出时：打开“任务管理器”→“详细信息”，结束路径位于本程序 runtime 文件夹下的 node.exe。
重启电脑也会结束它。

五、常见问题
------------
Q：Windows 提示“Windows 已保护你的电脑”（SmartScreen）？
A：Rhine Music.exe 没有购买代码签名证书，首次运行会出现。点“更多信息”→“仍要运行”即可。
   也可以右键压缩包 → 属性 → 勾选“解除锁定”，再解压。
   程序的源码和构建脚本都在 GitHub 仓库中，可以自行核对：scripts/package-windows.mjs。

Q：杀毒软件拦截或删除了 node.exe？
A：runtime\node.exe 是 Node.js 官方发布的原版文件。请把整个 V0.3.0 文件夹加入信任列表后重新解压。

Q：双击后没有反应，或弹出“启动未完成”？
A：改用 “启动音乐播放器.bat”，把黑色窗口里的信息保留下来。日志位于 music-data-v3\player-service.log。

Q：端口被占用？
A：播放器优先使用 5175，被占用或被系统保留（Hyper-V、WSL、Docker 会保留一段端口）时自动顺延到 5176–5184。网址以浏览器地址栏为准。

Q：扫描后有些歌不能播放？
A：浏览器可直接解码 FLAC、WAV、M4A、MP3、AAC、OGG 和 OPUS。DSD、AIFF 等格式只会进入曲库，不保证可播放。

Q：路径里有中文、空格或括号可以吗？
A：可以。曲库和解压目录都支持。
