# V0.4.0 缩略图总览与真实专辑列

日期：2026-10-02。用户追加要求：歌手或分类中有多少张专辑，就显示多少张；同时在高级设置保留原有填充方式。

## 两种阵列

设置 → 高级设置 · 专辑阵列 → 专辑列显示。

- **填充画面**：默认；保留重复列、重复专辑的循环实例池，维持原先满屏阵列。
- **真实专辑列**：每个真实专辑对应唯一整数行列；短列之后、列首之前和实际分类以外没有替补实体或可点击空壳。按歌手或流派使用真实归组；按专辑名字沿用每 12 张一列。

切换立即生效，自动保存，保留当前歌曲和选择；将原循环位置转换为唯一行列，同时补偿相机与轨道坐标以保留选中盒体的世界位置。音乐、详情导航和首尾循环仍可用，首尾导航回到该列真正的首张/末张，而不是移动到它的重复副本。

内部仍使用 9 列 × 48 行的可见实例池，不为整个曲库一次分配模型；滚动时换入对应真实条目。实例变换、封面变换、悬停与点击射线均检查真实行列，池中越界位置不显示。这里的“只出现一次”指场景身份，离开视野的真实专辑会按正常可见池机制暂时不渲染。长列和大量歌手不会因为关闭重复而一次绘制全部曲库。

## 缩略图模式

点击“缩略图模式”或 V，镜头连续拉远；Esc / V 返回近景。2026-10-07更新：点击列名只原地向右展开「进入 →」，点击进入才定位到该列记忆位置并返回标准视图，不自动打开详情。点击盒体仍选中并返回近景；Enter可打开当前选择。底部两箭头继续切换当前排列的列。

总览保留品牌、当前歌名、播放/停止、返回按钮与列导航，隐藏浏览正文、滑尺、顶部其他入口、运行状态及调试面板。顶部保留布局并渐隐，避免播放/停止按钮跳位。说明、返回和切列控件以及每个标签均有独立退入场；打开设置/详情和重播开场使用明确的退出路径；扫描后曲库变空时也会退出总览，避免用户困在没有返回按钮的空界面。

2026-10-07：三维池边缘列从基底平滑伸展/收回，封面与盒体同步；标签持续跟随投影与边缘可见度。完整设计、历史依据及多歌手验证见[动效复核](MOTION-REVIEW-2026-10-07.md)。

镜头使用临界阻尼进度衔接到俯视 43°、水平斜视 28°、距离 172 的取景；景幅按屏幕宽高比调整。镜头仍走同一 camera motion，减少动态效果直接到终点。整体动效倍率只应用一次。

2026-10-03：真实列在缩略图中改为**整列中心对齐**。奇数张对齐中间那张，偶数张对齐中间两张之间；单张列沿用该张中心。长短列围绕同一基准向前后展开，避免偶数列总偏向一边。进出总览时，列偏移与镜头共用连续进度；返回近景恢复原有选中专辑位置，不改专辑次序或列记忆。

居中只改变显示坐标，专辑仍使用原整数行列身份。每列的 48 行可见池跟随自己的居中位置取样，长列中段仍有真实实体；盒体、封面、选中及归位盒体共用偏移，点击继续定位原专辑。

## 列标签

标签来自当前真实音乐库归组，显示名字、序号与实际张数，而不是可见重复实例数。位置由真实三维锚点投影到页面，随镜头和行列移动。填充模式为每个实际分类选择最近的一条重复列作为名字锚点，避免同一分类反复贴相同标签。

真实模式将标签行锚点限制在该列实际首尾，并跟随列偏移。总览完成后，标签对应整列中心：奇数列贴中间专辑，偶数列贴中间两张之间。过渡期间仍限制在实际列范围内，避免短列标签悬挂在空白处。窄屏会剔除重叠和边缘标签，优先保留选中列；仍可用箭头切列，不承诺所有列名在手机同屏显示。

标签按钮按列身份复用，避免每次投影重建 DOM 导致键盘焦点丢失；焦点所在列离开屏幕时转交总览开关。
