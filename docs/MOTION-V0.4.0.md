## 依据与设计取舍

已阅读 `../视频分析-768017020/分析报告.md`，目视复核 `keyframes.jpg` 中阵列建立、选中停驻、抽取和特写节点，并阅读原 `BootSequence`、品牌轮廓和原版音乐启动实现。

参考片段的主要品质来自独立轨道之间的次序：空间建立、确认停驻、抽取减速、文字揭示。它不是所有元素同时套用一个 easing。原片分析能证明投影、遮挡与分段节奏，不能唯一推导相机坐标或材质参数。本次 2D 序章是为音乐用途重新编排，保留品牌轮廓、细线圆环、米白/深夜色系与克制橙色节点；没有声称逐帧复制未包含在此参考片段中的片头。

标语逐字使用 **回到按专辑听歌的慢私心**，无额外标点、不替换“私心”。使用一个完整文本节点；对话框的可访问名称也包含全句。两种主题和竖屏保持清晰对比，不在标语静读段加入跳字、闪烁或持续缩放。

## 开场轨道

| 片头时间 | 轨道与作用 |
| --- | --- |
| 0.12–0.82 s | 左上品牌轻入，建立与音乐主页共用的锚点 |
| 0.24–1.64 s | 原品牌连续轮廓描绘；符号稍后出现 |
| 1.64–3.28 s | 双层细轨道接棒，有限角度转动与橙色节点强调 |
| 2.72–3.58 s | 标语短距离上移并解除下沿裁切；无独立逐字延迟 |
| 3.58–5.70 s | 全句完全可读、位置固定，至少 2.12 s 静读 |
| 5.55–6.40 s | 先收细线与副标题，再退出主句和品牌 |
| 6.32–6.82 s | 背景平滑透明化，6.40 s 起真实三维阵列推进 |
| 6.40–11.60 s | 沿用原 21.92–27.12 s 的 live 阵列时间，不自动打开专辑 |
| 终点后 720 ms | 背景阅读层、页眉、导航内组、提示错峰显现，显现完成前保持交互锁定 |

`MusicBootFrameClock` 仍以每帧至多 50 ms 推进；着色器冷启动或后台恢复不能消耗未实际呈现的片头。后续冷启动修复将预编译与纹理准备放到片头开始前，前 6.32 s 二维底纸完全不透明时暂停 WebGL 提交，底纸消退前恢复，首个三维时间仍为 21.92 s。开场不受全局 0.25×–3× 动效速度设置影响，音频播放也不受影响。

跳过按钮、Enter 和 Esc 均可结束开场。跳过进入待选阵列。重播继续使用 `boot.replay()`；自动启动、显式重播及播放过程中变更“减少动态效果”均尊重该偏好。片头退出恢复原 `inert`/visibility 优先级及合适的焦点；旧回调通过 revision 失效处理。

## 详情交互次序与打断

- 修复首次打开详情时浏览文字退场与抽取同时启动的问题：现在先完成浏览文字退场，再调用 `enterCamera`；等相机与抽取落稳后呈现新详情文字。
- 在浏览文字退场期间发生多个选择时，仅保留最后目的地。先退字，再移动该专辑所在行列，落稳后抽取；不误用“已经进入详情”的快速换盒路径。
- 详情上一张/下一张保留既有串行机制：退详情文字 → 同一详情构图内旧盒归位、新盒抽出 → 新文字进入。搜索定位保留先回架、再移动、再进入的路径。
- `SurfaceTransition` 从当前浏览器计算的 opacity/transform 继续。临近终点的反向输入按剩余透明度距离缩短过渡，最小 72 ms，避免只差几像素仍重新走完整 360 ms。旧完成回调不能关闭新面板。
- 将详情文字水平进入/退出距离由 36/52 px 收敛到 24/32 px，上下型浮层由 12/8 px 收敛到 10/6 px。保留进入快收束、退出加速的原曲线，降低大段文字位移。
- 对位置连续与回调次序做测试；此处不宣称所有 UI 反向具有严格数学上的速度或加速度连续。已有标题字轮保留其当前位置与速度采样机制。
- WAAPI 仍保存基准时长、仅用 playbackRate 应用全局倍率；CSS 与场景各用各自单一倍率入口。未增加二次缩放。

## 验证边界

片头固定节点预览不包含 WebGL，也不代表 GPU 性能或完整 live 场景的视觉验收；整体验收应同时使用主应用的 demo 曲库入口验证三维交接、跳过、设置重播与真实数量模式。自动化 DOM/WAAPI doubles 验证的是时序、取消与倍率逻辑，不替代设备帧率测试。没有新增声音素材或假设用户授权播放音乐。
