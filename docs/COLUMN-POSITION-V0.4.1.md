## 用户路径与原因

搜索定位某歌手较深处的歌曲 → 返回主界面 → 浏览其他歌手 → 再经过原歌手列。应用会读取该列此前选中的专辑，但旧场景仅给无方向的搜索定位或进行中的定位启用距离适配轨迹。带左右方向的列记忆恢复仍使用固定速率弹簧，跨许多行时造成过快的初段移动；不是歌曲搜索请求在后台重新执行。

现在跨列且相差超过一行的恢复，也使用既有 1.4–2.4 秒距离适配轨迹，四个位置轨道同步缓起缓停。原相邻行、近距离列切换及详情内部切换保持原节奏；全局速度仍只应用一次，减少动态效果优先。

## 高级设置

位置：设置 → 高级设置 · 专辑阵列 → **保留每列浏览位置**。

- 默认开启；旧配置中没有此项时也开启。开关选择保存在当前浏览器的本站偏好中。
- 开启：恢复各列当前会话中上次浏览的专辑，并在较远回位时使用舒缓轨迹。
- 关闭：按用户选择，保持当前实际显示的阵列深度，选中目标列的邻近专辑。填充排列保留所处的正/负循环位置；真实排列不选择不存在的行，较短列夹在最近的首末专辑。
- 开关本身不选择专辑、不移动镜头、不改变播放。关闭时不读写列记忆；重新开启会记下当前列的位置，其他列的既有会话记忆保留。列位置记忆本身仍不是跨页面会话存储。
- 左右箭头与缩略图标签“进入”共用选择规则。“进入”无论记忆是否开启，都保持同一缓起缓停节奏。

关闭记忆时，目标来自实际 rail 的显示位置，而不是尚未到达的旧选中目标。方向请求携带明确物理行；缩略图进入携带明确物理格与 guided 意图。连续请求合并保留这些信息，横纵交替或循环首尾不会退回旧目标所在的另一周期。
