# V0.4.0 本地实施与决策日志

日期：2026-10-02。基线：V0.3.1，包括其未提交的光效、动画倍率与制作人员查询修改。新目录独立复制，不含旧 Git 目录，不改旧版或个人音乐文件。

## 用户确认

- Mac 原生 CoreAudio 输出，可选择设备；保留浏览器播放。独占 DAC 与自动采样率切换不在此次确认范围。
- 标语保留原文：回到按专辑听歌的慢私心。
- 暂不传 GitHub；做好本地更新日志、设计日志和测试。

## 实施顺序

1. 音频：核对官方资料与本机能力，统一解码、隔离缓存、浏览器兼容播放、原生设备输出和端到端样本测试。
2. 盒体：核对薄壳、窄边高光与磨砂区，重建可复现几何；内嵌封面保持比例，检查实例化与详情一致性。
3. 开场：标语、品牌序列衔接实时阵列；跳过、减少动态、重播不破坏播放。
4. 总览：拉远镜头、列名投影、简化控件、点击列或专辑与返回路径。
5. 编排：文字退出、镜头和盒体移动、落稳、文字进入分轨；快速反转、倍率和后台恢复回归。
6. 联调：构建、适用自动化、实际浏览器暖昼/深夜和宽窄屏交互、隔离音频播放。记录通过结果和未覆盖范围。

并行推进音频、模型、开场与动效；主线整合总览、UI、验收与日志。只有确有视觉差异值得保留时才建立 a/b 候选。

## 追加确认与实施结果

- 用户追加真实阵列需求：高级设置同时提供“填充画面”和“真实专辑列”，原填充方式为默认，选择自动保存。真实模式不为短列或屏幕外重复专辑。
- 音频、模型与动效并行实现，主线完成总览、有限阵列、界面集成与浏览器验证。没有额外 a/b 副本；可切换设置已能直接比较两种阵列与两种输出。
- 本机没有 Blender 工具链，本轮以 Three.js 可复现脚本生成 GLB，保留旧 .blend 历史源，新增脚本与描述文件作为 V0.4.0 的实际源。没有宣称旧 .blend 包含新模型。
- 三维模型、音频与总览交叉审查发现的问题修复后纳入回归，具体证据见各专项文档及 REVIEW-V0.4.0.md。
- 2026-10-03：按用户追加要求，完成启动重负载、重载资源释放与页面生命周期排查。只有一个 V0.4.0 候选，全部修复合入该目录。实测和未复现边界详见 STARTUP-V0.4.0.md；保留默认画质，不修改浏览器或系统设置。
