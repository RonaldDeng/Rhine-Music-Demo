界面来自 V0.5.0 构建，通过隔离演示数据展示 13 位虚构歌手、29 组专辑与 99 个独立版本实例。曲目名称、年份、时长和计数均为合成数据，无可播放歌曲，不表示真实曲库播放验证。该展示曲库独立于应用内置的三张封面演示。

18 张抽象封面通过 OpenAI 内置图像生成工具逐张生成。提示词使用本地参考图归纳出的色彩比例、饱和度与明暗层次，并分别设计新的抽象构图；原始参考图未上传到生成工具，也未加入公开素材。配图保留高饱和色块与灰白、淡粉、墨绿、深色之间的差异，同一专辑的多个版本复用封面。来源与资产边界见 [NOTICE](../../../NOTICE.md)。

主界面与总览截图直接保存浏览器的 2100 × 900 画面。设置图由两张同尺寸截图分别裁出 700 × 800 面板，再以 24 像素边距和间隔并排；版本图由完整截图裁出音乐库窗口。裁切、拼接没有缩放或重绘界面内容。

本次仅更新主线文档与配图，不改应用功能、内置演示、v0.5.0 标签或已发布的源码 ZIP。原 `library-introductions.png` 为专辑介绍流程的早期界面，仅保留给 [本版验证记录](../../REVIEW-V0.5.0.md) 引用，不再作为 README 默认展示图。生成过程、配色分析、原始参考图及本地对比页面均不随仓库分发。
