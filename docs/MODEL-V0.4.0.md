# 专辑盒、壳内纸面与封面维护

文件名保留以兼容现有文档链接，内容已按 V0.5.0 当前源码整理。旧模型、截图和本地视频分析过程不作为此页的运行依据。参数以 [music-model.ts](../src/music-model.ts) 为准；当前模型由 [music-cd-asset.ts](../src/music-cd-asset.ts) 指定。

## 结构与坐标

- 盒体为 **3.996 × 3.35 × 0.14**，中心 `(0, 1.85, 0)`。
- 磨砂侧条宽约 `.26907`，玻璃主体宽约 `3.72693`；列中心距为 `4.746`，保留 `.75` 净空。
- 纸面为 **2.98 × 2.98**，中心 `(0.14, 1.85, 0.027)`。
- 后托前表面 `z=-0.032`，纸面 `z=0.027`，前盖后侧 `z=0.052`，前侧 `z=0.070`；纸面、前盖与周框不共面。
- 场景、导航、灯光追列共用 `MUSIC_COLUMN_SPACING`；原版档案入口的列距独立保留。

当前几何直接按最终尺寸生成，载入后不再对旧盒进行非均匀拉伸。音乐盒不包含原版档案的双环、螺丝或机械内构；昼夜共用同一份几何。

## 三组物理材质

以下数值来自当前 `MUSIC_GLASS_FINISH`。光学厚度是材质参数，不等于几何厚度。

| 材质兼容名 | 结构 | 深夜粗糙度 | 暖昼粗糙度 | 深夜 / 暖昼透射 | 深夜 / 暖昼光学厚度 |
| --- | --- | ---: | ---: | ---: | ---: |
| Frosted_Polymer | 薄磨砂前盖 | .34 | .40 | .96 / .94 | .018 / .022 |
| Ivory_Edges | 高磨砂侧脊与肩部 | .25 | .52 | .88 / .64 | .060 / .100 |
| Optical_Diffuser | 后托、周框与挡位 | .38 | .46 | .80 / .70 | .038 / .050 |

非金属、IOR 1.46。进入详情仅将主盖粗糙度柔化至深夜 `.27`／暖昼 `.34`，不覆盖侧条层级。暖昼侧条必须比承托条更密、更磨砂；其衰减距离为 `2`，颜色 `#e7e1d8`。深夜侧条保留其已确认的材质，不能为了调整暖昼改写深夜效果。

阵列实例、选中盒与归位副本共用材质规则和约 650ms 主题过渡。音乐入口保留详情拖动；独立 360° 查看、拆解与重组属于原版档案入口。

## 壳内印刷与透射分区

纸面为不发光的 Lambert 材质，位于前盖之后。它接受漫反射与阴影，输出限制在原图颜色上限，不能用玻璃高光漂白封面；详情与归位也不更换亮度基线。

主盖按本地 XY 坐标计算纸面距离：纸面及向外 `.015` 内采用 `.16` 的透射 LOD 系数，在 `.015–.15` 范围平滑恢复为 `1.0`，使邻近纸面保持清楚，外侧玻璃继续柔化远处阵列。分区随实体与实例共同移动，不额外增加颗粒噪声、纹理或渲染 pass。

`shadeMusicGlass` 在阵列和选中路径接入并防止重复注入。这是实时屏幕空间透射的定向近似，不等于精确多层光线追踪；非方形图片的透明留白仍使用方形纸面范围。

## 封面与资源所有权

真实图片使用 contain 算法完整放入同一纸面，保持比例且不借用其他专辑封面。缺图或读取失败使用纯本地 800×800 的 B 方案排印封面，保留完整英文单词和歌手署名。

图集、高清选中纹理与归位快照共用 `paintCover` 的逻辑绘制坐标及相对留边。图集禁用整图 mipmap 和跨格各向异性过滤，并把采样约束在目标格边缘；选中封面使用独立纹理与既有质量设置。

同一图片解码请求共享，先复用已显示内容再补齐清晰度。晚到请求必须匹配代次、当前 key 与存活状态；归位副本有独立画布／纹理，切换专辑不能使其变成新封面。图集并发、局部上传、缓存与释放约束见 [初始化说明](STARTUP-V0.4.0.md)。

## 重建与检查

- 源：`art/build-music-case.mjs`，读取 `src/music-model.ts` 的几何及材质。
- 描述：`art/music-case-v043.json`。
- 运行：`public/assets/music-case-v043.glb`，通过带哈希的资源 URL 加载。
- 重建：`node art/build-music-case.mjs`；使用现有 Node.js 与 Three.js，无需下载模型或读取私人封面。
- 历史 Blender 源继续作为来源保存，不能把它冒称为当前生成器的可编辑源。

`node scripts/check-music-model.mjs` 检查实际运行 GLB、结构、包围盒、纸面间隙、材质和主题；`npm run check:cover` 检查比例、换行与异步所有权；`npm run check:lighting` 检查共享坐标与受光。当前执行结果见 [V0.5.0 验证](REVIEW-V0.5.0.md)。代码或几何检查不替代实际浏览器中的像素、动画及主观质量检查。
