# V0.1.1 发布检查

日期：2026-09-25。基于 v0.1.0 的 macOS 修订版本，原 V0.1.0、V3 工程及个人音乐数据保持原状。

## 修改

`src/music-theme.css` 的深夜渐变原先同时包含横向右侧遮罩和纵向边缘遮罩。竖屏中专辑信息已移至画面下方，但横向遮罩仍覆盖场景右侧。

本次新增可插值的 `--music-side-veil-opacity`：沿用应用的 `data-layout="portrait"` 判定，竖屏为 0，其他布局为 1，仅调节横向渐变各色标透明度。布局切换复用既有 650ms 颜色过渡，连续反向从当前值衔接；纵向边缘与文字区域底色保持原样。减少动态效果通过既有 `transition: none` 直接切换。初始竖屏在启用过渡前完成布局，不播放额外遮罩淡出。

版本号、README 下载链接和变更记录同步更新为 v0.1.1。依赖版本、播放与曲库逻辑未变，数据仍默认使用工程旁的 `music-data-v3`。

## 验证范围

- 使用锁文件重新安装依赖，执行 TypeScript 和 Vite 生产构建、档案导出与 PWA 清单生成。
- 静态复核主题样式导入顺序、选择器覆盖、横竖屏端点、主题切换及减少动态效果路径。
- 核对版本和锁文件、当前文档链接、Git 差异，以及打包清单、ZIP 完整性和校验值。

遵循现有验收约定，不追加浏览器或自动功能测试；实际竖屏观感由用户体验确认。既有 Vite 共享代码包体积警告保留，不影响构建完成。基础版本的清理与检查记录见 [V0.1.0](RELEASE-V0.1.0.md)。
