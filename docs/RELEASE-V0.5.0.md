# V0.5.0 · 发布说明

发布日期：2026-10-13。macOS 本地源码发行版，比较基线为当前本地 V0.4.1；中间迭代的最终改进合并在本次发布中，旧版本目录及 Git 历史保留。

## 相比 V0.4.1 的主要更新

- **音乐库与设置**：主屏音乐库负责浏览和搜索；设置分为音乐库设置／画面与声音，固定标题、独立滚动，切页保留输入、预览与位置，统一文字层级和内容动效。
- **自己的 AI 补专辑介绍（实验）**：单文件 `agent.md` 任务，支持分批、JSON 预览、旧结果核对、明确替换及备份导入；详情保留来源、作者和原文入口。播放器无需 AI API Key，任务由用户自行交给外部 AI。
- **开场与总览**：中央英文标语 1.8 秒接三维 5.2 秒；三维各列独立时差并连续进入常态缓动。新增完整歌手网格和全比例开关，修复投影名牌下跳、暗淡与挤压退场；总览专辑保持齐平。
- **模型、封面与布局**：盒宽 4.45→3.996、封面 3.06→2.98、音乐列距 5.2→4.746；缺封面采用本地 B 文字排印，统一外围边距，横屏详情使用右侧五分之二。增加可隐藏的歌曲衔接快捷按钮。
- **晨雾／月影**：主题更名并保留原配色；改善晨雾稳定灯光、磨砂边条、详情遮罩与内容交接。移动灯带增益默认 11×、可调 0–20×，支持仅重播三维入场。
- **维护与分发**：修复字体预热无限等待和介绍结果请求上限；更新两项有安全公告的依赖。清理原 PV 输入采样、研究材料、旧产物和比较服务，以显式清单生成源码包，保留模型源码、上游署名、许可和原版入口。

真实列、浏览记忆、三档歌曲衔接、浏览器与 CoreAudio、多格式解码和减少动态效果均为已有能力，继续保留。[完整更新](../CHANGELOG.md) · [当前设计](../DESIGN.md)

## 下载与运行

- [Rhine-Music-Demo-v0.5.0-macOS.zip](https://github.com/RonaldDeng/Rhine-Music-Demo/releases/download/v0.5.0/Rhine-Music-Demo-v0.5.0-macOS.zip)
- [SHA256SUMS.txt](https://github.com/RonaldDeng/Rhine-Music-Demo/releases/download/v0.5.0/SHA256SUMS.txt)
- [GitHub Release](https://github.com/RonaldDeng/Rhine-Music-Demo/releases/tag/v0.5.0)

完整解压后进入 `V0.5.0/`，双击 `启动音乐播放器.command`。这是源码包，不是 `.app`，不附带音乐。需要 Node.js ≥22.12.0；完整解码与无缝播放需要 FFmpeg／ffprobe，原生 CoreAudio 输出另需 Apple Command Line Tools。首次启动联网安装锁定依赖并在本机构建；普通使用无需 Blender。

源码附件只包含显式清单内文件，不包含 `node_modules`、`dist`、私人曲库、配置、缓存、日志、AI 任务或结果导出。上游及非代码资产来源见 [NOTICE](../NOTICE.md)，分发过程见 [分发范围](DISTRIBUTION-V0.5.0.md)。

## 从 V0.4.1 升级

先停止旧版音乐服务，把 `V0.5.0/` 放在旧工程同一父目录，继续使用旁边的 `music-data-v3`；保留旧工程。不要让两个版本同时写入同一数据目录。音乐文件和标签只读，浏览器偏好按浏览器／端口分别保存，主题内部 `day`／`night` 键继续兼容。

新介绍功能默认保留已有正文，提交前备份；它不保证每个平台都能查询成功。全文使用仍需明确依据，批量模式不放宽来源与许可要求。

## 验证与边界

发布检查的实测环境、构建标识、通过及跳过项目集中在 [V0.5.0 验证记录](REVIEW-V0.5.0.md)。完整检查包括锁文件安装、生产构建、`check:v050`、浏览器离线音频对照和源码分发检查；实际源码 ZIP 另核对文件内容、权限和解压构建。

本轮使用隔离合成数据，不读取私人曲库，也不自动查询外部 AI 或资料平台。既有视觉验证按具体修订记录，不能当作本次重新逐帧验收；本次没有重做用户已确认并要求停止的遮罩检查。缺失真实格式样本会明确跳过。

音频仍使用共享输出；不承诺 bit-perfect、独占输出、Native DSD／DoP、任意音频编码或外接设备兼容。无缝准备不及时或资源不足时会说明并降级。Windows 与在线曲库参见独立维护的 [社区版本](COMMUNITY-VERSIONS.md)。
