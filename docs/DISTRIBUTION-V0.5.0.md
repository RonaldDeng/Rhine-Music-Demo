## 检查方法

显式文件清单为 `scripts/distribution-files.json`。`npm run check:distribution` 先执行合成负面测试，再只读检查当前源码和完整 `dist`，不只依赖 `.gitignore` 或离线缓存清单。

- 清单每一项都必须存在，删除文件时同步收缩清单，不能留下旧素材重新进入的空白许可。未知文件不自动放行；拒绝私人索引、配置、任务/结果 JSON、研究素材、旧采样路径以及符号链接。
- 即使导出任务改名放在已允许的文档路径，也检查其内容并拒绝。
- 旧采样只保留 SHA-256 指纹用于排除检查，不复制录音或 PCM 作为测试样本；可识别已知采样文件、内嵌 base64 及改名后的数据。
- 核对源码相对依赖、运行及许可必需文件、版本一致性、启动器权限、public 资源与 dist 副本一致性、离线清单路径，以及可见本机路径和凭据特征。
- 从构建 index.html 追踪实际 JS/CSS 引用与动态块，拒绝未被入口引用的孤立构建文件；文件名符合 Vite 命名也不能自动放行。
- 默认只读，不上传。可选本地打包仅复制白名单文件，复查暂存内容，并核对 ZIP 清单、CRC、解压后的字节及执行权限；不会覆盖已有归档。macOS 使用系统 bsdtar 写入正确的 UTF-8 文件名标志，排除主机扩展元数据；真实打包回归覆盖中文启动器及两种系统解压方式。本次发布使用此路径生成源码 ZIP，并复查实际附件与提交文件内容；执行结果见 [验证记录](REVIEW-V0.5.0.md)。

这些检查针对已知风险与明确的分发范围，不承诺识别任意编码、任意版权归属或所有秘密。字体、模型、标志、上游内容及用户后来引入的资料仍遵守 [NOTICE](../NOTICE.md) 和各自来源许可。
