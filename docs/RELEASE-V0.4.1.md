# V0.4.1 发布检查

发布日期：2026-10-07。发布仓库为 `RonaldDeng/Rhine-Music-Demo`，标签 `v0.4.1`，面向 macOS。此版包含未单独公开发行的 V0.3.1 / V0.4.0 工作及后续 V0.4.1 修复，具体变化见 [CHANGELOG](../CHANGELOG.md)。

## 发行内容

- 多格式本机解码、CoreAudio 设备选择、DSD 转 PCM、磨砂专辑盒与缩略图总览。
- 搜索缓起缓停、歌手标签展开后进入、总览控件过渡、播放控件固定、真实列独立居中与首尾限制。
- 默认保留的每列浏览位置偏好、开场品牌与标语整理、播放歌名括号裁切修复。
- 三档歌曲衔接，浏览器与 CoreAudio 真实预排无缝接续；资源限制及降级提示见 [衔接说明](SONG-TRANSITIONS-V0.4.1.md)。

## 实际检查

环境：macOS、Node.js 26.3.0、npm 11.16.0；使用隔离数据与合成音频，没有读取或改写个人曲库，也没有自动查询私人歌曲资料。

- `npm ci --no-audit --no-fund`：锁定依赖安装成功，未升级依赖。npm 提示 esbuild / fsevents 的安装脚本未列入 allowScripts；未更改批准设置，后续构建正常完成。
- `npm run build`：TypeScript、Vite、档案导出及 PWA 构建通过。本次补充更新后的资源版本为 `69d053c7c8f37f71`，75 个文件、约 28.6 MiB。Vite 原有共享产物超过 500kB 的提示保留，不属于构建失败。
- `env -u RHINE_TEST_APE npm run check:v041`：完整通过。Node test-runner 累计执行 321 项，320 通过、0 失败、1 跳过；其中部分播放器与展示检查在不同检查组重复执行，另有脚本断言均通过。
- 唯一跳过是未提供官方 APE 样本；没有把可索引或未执行的样本测试算作格式验收。
- 音频子集合累计 126 项，125 通过、1 跳过；包含真实 Swift 编译、生产 CoreAudio 离线渲染及零音量设备播放。
- `npm run check:audio:browser-render`：另用已有 Chrome 154 / Playwright 执行。6 个 OfflineAudioContext 场景各渲染 16,000 帧双声道，完整输出与接缝对照的最大误差均为 0；包含双向采样率、非整数源帧、取消下一首和跳转后接续，不连接声音设备。
- 原生专项直接编译生产 Output，验证连续多首、双向非整数采样率转换、单/双声道、缓存租约及取消。分拆立体声波形的 96,000 个样本逐一一致；真实设备在零音量下由原生时钟自动接续，界面不额外触发 play。
- 独立复核了预加载撤销、跨曲目边界的暂停/跳转/换后端、极短歌曲结束与状态同步。源码冻结后在清理后的发行目录再次执行完整检查。

## 未覆盖范围

未在所有 macOS / 浏览器版本、所有编码变体或 USB / 蓝牙设备上长期试听；没有执行完整能耗或性能基准。模拟、离线渲染和零音量设备检查不等于这些范围都已验证。

无缝接续依赖下一首按时准备，并受内存、文件大小、声道数和设备变化影响；无法满足时会提示并退回普通切换。浏览器无缝需要 FFmpeg，原生下一首使用当前引擎采样率的 Float32 PCM。所有输出仍不承诺独占、自动硬件采样率或 bit-perfect；DSD 不提供 Native DSD / DoP。
