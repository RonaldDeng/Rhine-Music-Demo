# Observatory / 观测室

三个 Ogg 文件为本项目原创程序编配的同步循环声部，供原版入口和音乐界面氛围音乐使用。配乐无原片采样、无外部录音、无人声。

源谱及合成：`scripts/render-audio.mjs`；音效合成：`src/audio.ts`。
随项目采用仓库 LICENSE。渲染脚本只将运行所需的 Ogg 声部写入本目录；独立试听文件与 `score.json` 指标写入本地 `.tools/audio-render/`，不随源码或构建分发。

## 逐字输入短音

V0.5.0 已移除原 PV 逐字输入采样、嵌入的 PCM 数据、解码缓存、试听文件及提取研究素材。旧版本保留的历史素材不属于此版本的分发内容；本次移除不改变原作权利归属。

保留的原版入口 `?original=1` 使用 `src/audio.ts` 中新增的原创程序输入短音：两个轻音量正弦振荡器配合短衰减包络，不使用录音，不模仿原 PV 采样。新短音随程序代码采用 LICENSE。原版文字揭示时序保持不变。

音乐主界面及其开场没有调用逐字输入短音；切换专辑、切换歌手、打开、返回、系统点击和窗口打开的原有合成音效保持不变。三轨运行配乐继续保留；未使用的独立试听 MP3 不再分发。
