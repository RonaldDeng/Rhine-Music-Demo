# 歌曲衔接图标

V0.4.3 右上歌曲衔接按钮的独立 SVG 素材。沿用界面线性图标：24 × 24 viewBox、1.5 描边、圆角线端、`currentColor`，常规显示 17px，小屏显示 16px。

- `fade-in-out.svg`：两条交叠的音量包络曲线，表示淡入淡出。无箭头，不采用随机播放图标语义。
- `gapless.svg`：连续水平线表示连续声音，中间细竖线表示歌曲边界。
- `fade-out.svg`：单条下降的音量曲线，表示仅淡出。

按钮显示当前模式；淡入淡出或仅淡出使用主题强调色，无缝播放使用普通前景色。图形与颜色共同区分状态，按钮同时提供当前模式的文字无障碍标签。独立素材与应用内路径应同步维护。

图标为本项目原创 SVG，按项目代码的 MIT 许可保留。
