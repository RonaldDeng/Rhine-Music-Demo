# 外壳与移动磨砂检查 · 2026-09-09

> 历史开发记录：以下范围、参数与验证结论对应文中所述阶段，不代表 V0.1.0 本次已复验；发布版差异见 [验证记录说明](README.md)。

按用户提供的正面与局部截图，通过 Blender MCP 运行共享模型脚本；未使用参考视频作为交互背景。视效仍待用户实际审阅。

## 修改

- 顶边黄色嵌片改为约 0.25 × 0.2239；前面 z=0.206、顶部 y=3.7，与盖板齐平，具有真实嵌槽。原来的突出方块和左侧黄条删除。
- 螺丝只保留右上与左下，使用十字凹槽、齐平垫圈及盖板孔。周围 C 形压槽连同顶部回路、内边框与底部回路均在盖板后，最前深度为 0.168，小于盖板内面 0.174。
- 去掉前表面额外细阶与宽端盖。物理外缘仍可形成轮廓，盖板内的装饰刻线随磨砂模糊。
- 以移动边界替代原来的固定高度粗糙度渐变：进度 0 全部磨砂，0.5 上部清晰而下部模糊，1 全部清晰。羽化带为高度的 24%。原片时间曲线从 38.84 秒开始，39.0 秒约 0.51，39.56 秒结束。
- 主场景和 360° 查看器共享同一套资产与材质逻辑。内部六组光学网格的坐标及法线保持上一版。

## 验证

- `node --experimental-strip-types scripts/check-shell.mjs`：通过。内构位置及法线一致，螺丝仅分布在指定两角，嵌片顶边与前面齐平，所有刻线在盖板后；清晰进度与原片时间曲线单调，起止状态覆盖整面。
- `node --experimental-strip-types scripts/check-assembly.mjs`：通过。单体与六组拆解资产的顶点最大误差 1.688e-7，模型高度 3.70000005。
- `node --experimental-strip-types scripts/check-internal-optics.mjs`：通过。法线与截面最小点积 0.9997446，四种半透明内构材质与唯一连接带保留。前一轮的外壳不变断言由本轮的内构不变断言替代。
- `node --experimental-strip-types scripts/check-decryption.mjs`：通过。解密线、退出重入、减少动态效果及内构净空保持正常。
- `reference/decryption-check.html` 实际浏览器运行：8/8 通过。两段解密线共线、结束清晰与标记消失、近裁剪精度、磨砂过渡、反向切换保留镜头、拆解后切换、关闭后详情保持清晰、解密中退出清除标记。
- `npm run build`：通过。已有 bundle 大小提示仍在。
- 在对照页观察 0%、50%、100% 及斜视放大：初始整面模糊、中途上部先显露、结束内构与刻线清楚；嵌片无凸块侧面，黄条消失，只有两处螺丝。

## 入口与限制

`reference/shell-review.html`：打磨前后同镜头对照，使用同一套新版磨砂过渡；可拖动进度、以约 2.2 秒慢放清晰过程、检查顶部或螺丝局部。此页用于模型检查，标签复用产品资产。

`reference/decryption-review.html`：与原片同步逐帧检查，保留原时间码。实际详情为 `/?scene=detail`。

这是按图片与视频观察重建的外壳；刻线尺寸、玻璃光学和揭示速度仍是实时近似。当前没有声称与原片逐像素一致。源文件为 `art/rhine-archive.blend` 与 `art/archive-assembly.blend`；公共细节脚本为 `art/shell_reference_details.py`。
