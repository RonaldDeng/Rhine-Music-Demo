# 历史开发与验证记录

本目录保留上游档案终端、早期音乐适配以及 V2/V3 的设计取舍、复现方法和当时的验证结果，用于工程追溯。它不是 V0.1.0 的验收报告。文中的“当前”“本轮”“已通过”和“待用户验收”均属于原记录阶段，不能据此推断本次发布重新执行了浏览器、设备、播放格式或性能验证。发布功能、安装步骤与本次检查范围以项目根目录的 [README](../README.md) 为准。

## 与 V0.1.0 的主要区别

- V0.1.0 面向 macOS。历史 Windows、foobar2000、DAC 或 DSD 方案是旧讨论，不构成本版本的支持承诺。
- 音乐入口采用约 5.2 秒三维进场，不恢复历史 2D 身份片头或重播入口；进场结束停在待选界面，不自动打开详情。
- 音乐阵列每列显示 48 个循环位置；历史 32 行和 9 × 32 可见池记录不描述当前音乐模式，真实曲库数量不因循环展示而增加。
- 当前音乐盒运行尺寸为 4.45 × 3.35 × 0.14，封面为 2.98 × 2.98。V2 文档中的 5 或 4.65 宽度是调整过程；模型源文件的原始尺寸与运行时归一化尺寸也不同。
- 当前专辑详情保留 8° 水平斜视；抽取转正后段与左移连续衔接，收纳回中尾段与阵列转向、下降交叠。历史“完全回中后再下降”等严格串行描述只对应当时版本。
- 音乐端保留详情拖动旋转，独立 360° 查看、拆解和重组入口仍停用；原版档案入口保留自己的功能。
- 底部滑尺的旧稿保留作为方案来源，代码中的 `?nav=previous` 用于对照；记录里的试用措辞不表示 V0.1.0 发布后还需要完成同一次会话操作。

## 资料范围与复现

私人曲库规模、实际试听专辑名称及本机目录已从这些记录中移除。`reference/music-text-review.html` 使用虚构标题和艺人检查文字布局，不携带真实曲库数据。

V2 的本地界面截图、页面采样 JSON、参考录屏及其逐帧资料不随本次源码发布；保留的数字是历史技术测量结果。原 PV 的端面裁图也已排除，模型记录保留原片时间码供自行复核。依赖本地视频、参考帧、额外工具或运行中服务的审阅脚本，仍需使用者自行准备对应输入。

`docs/media/` 展示的是上游档案终端，不能当作 V0.1.0 音乐界面的截图。任何历史测试通过记录都不替代对当前代码和实际设备的重新验证。
