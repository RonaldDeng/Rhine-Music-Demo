# 文档同步解密试用版

> 历史开发记录：以下范围、参数与验证结论对应文中所述阶段，不代表 V0.1.0 本次已复验；发布版差异见 [验证记录说明](README.md)。

- 沿用项目原生实现流程；用户要求先做出效果试用，视觉节奏待实际反馈。
- `src/document-decryption.ts` 读取现有模型解密帧。合拢、保持及收束期间遮挡；模型开始清晰时触发 950ms 文字揭示，其中各行最多错峰 209ms。
- 以实际文字换行测量黑色遮挡条，通过行内裁切窗口向右退开；先加速、后长尾减速。正文节点与布局保持原样。此为视觉动效，不改变内容授权或导出。
- 覆盖英文标题、中文标题及分类、资料字段、摘要、研究记录与访问日志；导航、字段名和操作保持可识别。切换页签复用当前进度，完成后不重播；退回阵列后再次打开重新解密。减少动态效果直接可读。
- 用户指出横向滚动条后，遮挡宽度限制在文本容器内，正文仅允许纵向滚动，避免遮挡消失时可用高度变化。

## 验证（2026-09-09）

`npm run build` 通过；保留原有打包体积提示。

浏览器实际运行 `reference/document-decryption-check.html`，12 项通过：初始遮挡、摘要无横向溢出、解密中切页签仍遮挡、模型与文档揭示同步、正文位置稳定、揭示期间无横向溢出、结束清除遮挡、正文高度一致、收藏不重播、其他页签直接可读、重新进入遮挡、快速重入正常结束。

正文区实测 `clientWidth = scrollWidth = 636`、`clientHeight = 189`；横向滚动关闭。
