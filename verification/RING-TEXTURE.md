# 第一版内构恢复与磨砂修正 · 2026-09-09

> 历史开发记录：以下范围、参数与验证结论对应文中所述阶段，不代表 V0.1.0 本次已复验；发布版差异见 [验证记录说明](README.md)。

用户最终选择截图中对照页左侧第一版完整内构，要求恢复该版本，并反馈磨砂比原片更重。

## 实现

- 从 89c7742 的原始脚本恢复两组圆环及双连接带，保留全部原始几何、平滑法线、白色和橙色材质。通过 Blender MCP 重新生成单体、六组拆解模型及两个 .blend 源文件。
- 外壳保留已完成的齐平黄色嵌片、两处螺丝、盖板后刻线。reference/ring-study/assembly-before.glb 保存 dde61fd 外壳回归基准。
- 选中盖板粗糙度降至 0.42；折射采样模糊上限约为投影盖板高度的 1.6%，小尺寸预览与大尺寸展示采用一致比例。清晰过程单调减轻模糊，保留阵列与完全清晰端原始采样。
- reference/internal-review.html 同时展示原始第一版和恢复后的第一版。reference/decryption-review.html 可与原片按帧观察磨砂及清晰过渡。

## 验证

- check-internal-optics 比较当前与第一版的内部世界坐标、法线、原始材质，以及当前与 dde61fd 的外壳坐标、法线和材质，精度为 1e-5。
- check-decryption 覆盖解密曲线、盖板清晰控制、内构深度、折射采样与着色器替换；新增半尺寸、标准、双倍尺寸的模糊比例与单调性检查。
- check-assembly、check-shell 分别检查单体／拆解几何一致性与外壳细节、移动揭示。

原片仍存在几何、照明与实时折射近似差异。技术验证不代表用户已经确认磨砂最终观感。

最终结果：四项脚本检查通过；单体与拆解最大顶点差为 2.666e-7，高度 3.70000005，内构深度 -0.034 至 0.150。浏览器 8 项交互回归全部通过，覆盖解密、玻璃切换、快速反向、拆解中切换、退出与重新进入。原片 34.00 秒并排复核可辨识两组环体；第一版恢复对照两侧内构外观一致。

生产构建 npm run build 通过，保留既有包体大小提示。最终浏览器复核无着色器编译错误。

用户最终反馈：‘效果很不错’，确认保留恢复后的内构与本版磨砂效果。
