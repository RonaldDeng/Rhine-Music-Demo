# 清晰内构与解密验证

> 历史开发记录：以下范围、参数与验证结论对应文中所述阶段，不代表 V0.1.0 本次已复验；发布版差异见 [验证记录说明](README.md)。

日期：2026-09-09。用户要求参考原片 41 秒及 46–51 秒，详情解密后变清晰，查看器可切换清晰／磨砂，并修正详情大环闪烁。

## 模型

- Blender MCP 执行 `art/build_archive.py`，再执行 `art/build_assembly.py`；两者共用 `art/clear_reference_details.py`。保留 `art/rhine-archive.blend`、`art/archive-assembly.blend` 与导出 GLB。
- 两组环形内构采用分段闭合截面、斜肩、内孔、橙色弧段、84/52 根细立面肋和薄片连接带。左侧三根高塔完全省略。
- 内构深度范围为 -0.0340000 至 0.1500000，位于基板前面 -0.038 与盖板内面 0.174 之间。
- 六组拆解与单体的对应顶点最大差为 2.666e-7；组装高度 3.70000005。只改变组装关系，不更换不同的模型。

## 时间轴

| 原片时间 | 动作 |
| --- | --- |
| 34.24–36.04 | 两端沿同一对角线向中央延伸 |
| 36.04–37.72 | 保持完整黑线 |
| 37.72–38.84 | 两端向中央收束 |
| 38.58–39.30 | 中央验证点短暂停留 |
| 38.84–39.56 | 玻璃由顶部向下从磨砂转清晰（后续外壳修订，见 SHELL-REFINEMENT.md） |

曲线按本地 25 fps 视频逐帧测量，使用单调三次 Hermite 插值，保持非线性速度且不越界。两段端点均在同一个模型空间线段上计算，随相机投影；不使用固定长度线条淡入淡出。交互以 1.5 倍播放（约 3.63 秒），等到镜头与升降接近就位才开始。原片回放不压缩。减少动态效果时直接切换。

## 闪烁原因与修正

详情长焦相机与查看器有不同距离：详情约 72，查看器初始约 14.5。原详情近裁剪面 0.1 使大环的薄层表面落入相同深度量化格，在微小镜头变化下争抢像素。将主相机 near 改为 5；far 仍为 300，不移动相机或模型。理论 24 位深度步长在距离 72 处从 0.003088875 降为 0.000060768，约提升 50.83 倍。修正前可见的环面斑驳在修正后静帧中消失。

`reference/depth-check.html` 检查原片 27、27.2、27.6、28、29、30、31、32、34、36、39.6 秒，共 11 个镜头。使用旧 near=0.1 视锥筛选可见模型，再测世界包围盒距镜头的最近深度，最小为 16.662，大于新的近裁剪面 5。地面平面不纳入档案包围盒检测。此检查覆盖代表镜头，并非对每个可能交互姿态的数学证明。

## 检查结果

- `node --experimental-strip-types scripts/check-decryption.mjs`：通过。包含延伸/收束单调性、无过冲、阶段顺序、进出/减少动态效果/反向跳帧、实际材质 uniform 绑定、重组后材质更新、内构空间约束和深度精度。
- `node --experimental-strip-types scripts/check-assembly.mjs`：通过。
- `reference/decryption-check.html`：8 项真实应用检查通过；包括投影共线、解密结束后清晰且无标记、近裁剪面、磨砂中间态、快速反向切换保留镜头、拆解后切换、返回原详情、解密中退出。
- `reference/depth-check.html`：11 个代表镜头通过。
- `npm run build`：通过；保留既有包体大于 500 kB 的提示。

## 查看与限制

`reference/decryption-review.html` 提供原片与生产界面同时间码对照、逐帧、半速和四分之一速度；参考视频及 JPG 仅用于本地验证，不进入产品背景。`reference/model-review.html` 保留放大模型对照，左侧基线是本轮细化前的资产。

这是依据可见画面推演的三维结构，内部建筑用途、隐藏结构和精确截面无法从视频唯一恢复。镜头、光照和材质与原片仍有差异，不宣称逐像素一致。用户尚未确认最终视觉效果。
