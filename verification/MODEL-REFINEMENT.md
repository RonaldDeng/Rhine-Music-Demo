# 原片模型细化 · 2026-09-09

> 历史开发记录：以下范围、参数与验证结论对应文中所述阶段，不代表 V0.1.0 本次已复验；发布版差异见 [验证记录说明](README.md)。

本轮按用户要求放大原片模型，沿用逐帧观察与 Blender MCP 流程。参考为原片 37、39 秒特写及 39 秒顶部、端面放大；原片裁图不随 V0.1.0 源码发布，复核时按这些时间码自行提取。对照页包含 27.60、29.16、31.48、39.00 秒。

## 几何调整

- 两个光学环由压扁圆管改为闭合旋转截面，区分宽腔壁、斜肩、内孔台阶与细环；主截面采用 128 段。小环的香槟色嵌件保持在透明盖板后方。
- 顶部压槽沿参考增加折返与双侧槽边，放到盖板内侧；增加内周边、前沿细阶、框架接缝和刻度区支点。
- 螺钉由球面头与叠加黑条改为倒角圆柱、真实布尔凹槽和沉头垫圈。
- 材质名称、基线颜色和光照不变；共享标志、外包围盒、镜头及抽取运动沿用。
- 主模型与六组拆解资源均由 Blender MCP 执行脚本导出。使用 bpy.data.libraries.write 保存目标场景及依赖，不保存其他工作场景，也不更改当前打开文件路径。

## 复现与对照

通过 Blender MCP 在 Blender 内先执行 art/build_archive.py，再执行 art/build_assembly.py，分别提供脚本绝对路径 __file__。输出为 public/assets/archive-cassette.glb、archive-assembly.glb 及对应 art/*.blend。

reference/model-review.html 左侧可选择原视频或细化前，右侧为当前模型。两边使用基线灯光、同一时刻、相同相机及 1920×1080 渲染缓冲，支持 2×/3× 裁切放大。旧模型为本轮开始前保存的 reference/model-study/archive-before.glb。原片帧沿用本地 reference/motion，不进入生产构建。ArchiveScene.load 的可选路径供对照复用生产渲染逻辑，默认仍载入正式资源。

## 验证

- npm run build 通过；保留既有包体积提示。
- node scripts/check-assembly.mjs 通过：六组齐全，双向几何最大误差 2.3842e-7，重组误差 9.704e-7。
- node scripts/check-archive.mjs 通过：模型高 3.70000005，详情升高 4.05，归位净空及先转正后下降检查通过。
- 细化前 / 后：GLB 1,439,344 / 1,629,368 字节；三角形 39,544 / 41,528（约 +5.0%）；重复阵列每张使用的三角形 8,988 / 7,164（约 −20.3%）。主资源保持 11 组材质，拆解资源保持 14 个网格。此为几何统计，不是帧率提升承诺。
- 浏览器检查：31.48 秒前后阵列疏密和边界一致；39 秒放大检查环槽、边缘和顶槽。实际进入详情、打开独立查看器并测试拆解与重组。

原片透明折射、磨砂散射和镜头效果仍有差异。这是依据可见轮廓重建的细化，不代表恢复原片三维源模型；最终审美效果由用户查看对照判断。
