# 音乐播放器副本与过渡验证

> 历史开发记录：以下范围、参数与验证结论对应文中所述阶段，不代表 V0.1.0 本次已复验；发布版差异见 [验证记录说明](README.md)。

最新微调（待用户验收）：盒宽4.65；转正后段与左移交叠，左移速度提高5%；灰条跨流派在本体高度内收缩恢复。以下测量与检查为此前版本的记录，本轮未重新运行。

本轮仅修改 `RhineLabUI-Music-v2`，原工程 `RhineLabUI` 保留现有未提交状态。副本包括原有资源与源码，启动服务默认使用相邻 `music-data-v2`，原音乐源文件继续只读；没有推送到旧远程。

## 展示顺序

- 打开专辑：抽取与转正 → 正面居中 → 镜头取景将专辑放至左半屏 → 菜单从右侧淡入。竖屏保持上方模型与下方内容。
- 返回：菜单用 240 ms 向右淡出 → 专辑投影回中 → 镜头返回阵列且盒体归位 → 阅读区及底色用 720 ms 柔和淡入。
- 换专辑：沿用返回顺序，阵列镜头稳定后才提交选择；新轨道也稳定后再展开。连续输入保留最后选择，返回会取消尚未提交的换选。
- 左移与回中采用独立 1.45 s 连续轨迹。曲线起止速度和加速度为零，中断时保留现有运动状态；相机继续跟随该目标。相机测试中，前 0.2 s 位移约 0.22%，95% 位移约在 1.47 s 达到。
- 阅读区底色随同一可中断透明度动画进入，采用 `cubic-bezier(0.45, 0, 0.25, 1)`，避免大面积底色一开始快速出现。减少动态效果时直接落位。

相机就绪由实际镜头、速度、升高及轨道状态判断，不用固定延时替代。菜单退出完成回调才允许镜头返回；重播和曲库替换使旧回调失效。曲库异步重载保留期间最新的浏览意图，退出弹窗后恢复当前视图的输入。

## 模型与画面

已有 Blender 简化玻璃壳在运行时统一为 5 × 3.35 × 0.14，封面占 2.98 × 2.98，贴在壳体最前方；没有原片圆环与螺丝。封面保持独立、清晰的原始色彩。此次没有重新生成 Blender 资产。

玻璃盖板常态粗糙度 0.40、详情终点 0.30，边框 0.25、背板 0.40，弱化覆层镜面感。磨砂、高亮与扫描不改动图片材质。玻璃细节见 `MUSIC-GLASS-MODEL-V2.md`。

## 检查记录

- TypeScript 与生产构建通过。
- `npm run check:music` 覆盖曲库、播放器、阵列映射、抬起与波浪、相机、灯光、展示顺序和模型；展示控制器另包含 12 项顺序、中断、快速换选、重播及减少动态效果检查。
- 模型检查读取实际 GLB 边界，验证封面位于所有玻璃之前；三主题 × 三画质 × 三清晰度状态验证磨砂终点与图片材质隔离。
- 页面验证桌面 1280 × 720 和竖屏 390 × 844：专辑左右构图、菜单退出后镜头返回、连续方向键换选和竖屏阅读底色。竖屏为桌面浏览器视口模拟，不代表真实 iPhone 性能测试。
- 返回主视角的历史页面采样：阅读底色约 99 ms 时为 2.7% 不透明度（opacity），198 ms 为 18.1%，396 ms 为 77.8%，687 ms 为 99.7%。原始采样 JSON 仅用于当时的本地验证，不随 V0.1.0 源码发布。测试同时验证动画中断从当前透明度与位移衔接，旧完成回调不能隐藏新界面。
- 当时的界面截图、参考视频分析和逐帧对照仅保留在本地，不随 V0.1.0 源码发布；本文件保留技术结论，不提供这些私人验证资料的文件链接。

生产构建仍提示共享渲染包较大；没有新增构建错误。
