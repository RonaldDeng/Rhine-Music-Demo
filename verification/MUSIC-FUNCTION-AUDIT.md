# 原版操作到音乐播放器的适配审计

日期：2026-09-09。检查范围：`src/archive-main.ts`（保留的原 `main.ts`）、`src/model-viewer.ts`、`src/audio-settings.ts`、`src/quality-settings.ts`、`src/pwa.ts`。

本表记录原版功能和改造边界，不代表表内每项已在音乐界面完成。它不修改原版入口，也不把待确认的旧功能当成删除清单。已明确的方向是本地专辑/歌曲、真实音乐资料、封面与原实体结构结合，以及保留原 360° 拆解和重组。

## 可按已授权方向替换的数据与入口

| 原入口 / 控件 | 原动作 | 音乐适配建议与边界 |
| --- | --- | --- |
| `data-action="search"` / ARCHIVE INDEX / `/` | 打开档案检索 | 替换为音乐检索；检索专辑、歌曲、艺术家和已导入元数据。保留弹窗关闭、焦点恢复和空结果提示。 |
| `archive-search`、`data-filter`、`data-result` | 实时检索、类别筛选、读取命中档案 | 对应音乐库搜索和曲风筛选；点击专辑结果选中/打开专辑，歌曲播放由明确播放操作触发。 |
| `data-action="saved"` / SAVED | 浏览已收藏档案 | 对应收藏专辑；如同时支持歌曲收藏，需在文案中明确收藏对象。 |
| `data-action="bookmark"` | 增删当前档案收藏 | 对应当前专辑收藏。用稳定专辑 ID 保存；不要覆盖原 `rhine-saved` 档案收藏。 |
| `data-action="prev"/"next"`、`data-select`、`↑/↓` | 同列上/下档案、刻度选档 | 对应同类专辑浏览；继续保留循环、抽取和归位。不要悄悄把这些导航变为正在播放歌曲的上一首/下一首。 |
| `data-action="column-prev"/"column-next"`、`←/→` | 切换五类档案列 | 对应音乐分类/曲风列及选择记忆。动态曲库需支持不同长度和空分类，不再强制每类八张真实专辑。 |
| `data-action="open"` / FILE NUMBER / ACCESS FILE / `Enter` | 抽取档案并展开详情 | 对应打开专辑详情；保留原实体抽取、文档揭示与返回动画。 |
| `data-action="back"` / ARCHIVE OVERVIEW / `Esc` | 从详情返回阵列 | 对应返回专辑库；界面返回不应停止正在播放的歌曲。 |
| `data-tab="overview"` | 展示档案摘要 | 对应已有来源的专辑介绍、曲目及基础资料；资料缺失时明确空值，不生成虚假简介。 |
| `data-tab="notes"` | 展示档案研究记录 | 可承载用户要求的制作人员/唱片资料；仅展示本地标签或已确认来源。页签名称、字段替换属于音乐信息适配，原动画可复用。 |
| 详情 `DEPARTMENT / COLLECTION / RELATED / STATUS` | 科室、日期范围、人物、档案权限 | 按资料实际含义替换为艺术家、发行年份、曲风、唱片/曲目和音频格式等。不能把演示日期、人物或保密等级当真实音乐信息。 |
| `data-action="reset-search"` | 清空条件或从收藏转回全部档案 | 保留相同行为，文案换为专辑/曲目。 |
| `data-action="close-modal"`、模态内 `Tab/Shift+Tab` | 关闭和焦点约束 | 原样保留；音乐播放不中断。 |

## 必须保留的实体 CD 操作

| 原入口 / 操作 | 处理结论 |
| --- | --- |
| `data-action="model-viewer"` | 保留原独立查看器，音乐入口可写“360° 查看专辑模型”。不能替换成仅放大的平面封面。 |
| 查看器 `data-viewer="explode"` / 拆解档案 | 保留六组部件及原运动参数：紧固件、透明盖板、折射环组、光学核心、信息基板、背板与框架。 |
| 查看器 `data-viewer="assemble"` / 一键重组 | 保留原路重组、运动中反向切换和原状态提示。 |
| 查看器 `clear` / `frosted` | 保留清晰/磨砂切换，不能通过隐藏原内部环结构实现封面模式。 |
| 查看器 `reset` / `Home` | 保留平滑复位和拖动打断复位。 |
| 拖动、滚轮、`+/-`、方向键、触摸 | 保留旋转、缩放、平移；这些按键在查看器内不能继续驱动后面的专辑阵列。 |
| 查看器 `close` / `Esc` | 保留退出过渡、焦点回到入口、后台音乐继续。 |
| 查看器 `retry` | 保留模型加载失败后的重试，不能将模型失败误标为歌曲播放失败。 |

本次实现让完整封面成为透明盖板组的独立印刷层：`assemblyPart="cover"`，跟随该组的 `z = 1.85 × spread` 一起拆开与重组。方形、横幅、竖幅封面都采用 contain 保持比例，不裁切。印刷层离开后能继续观察原内部环结构；它不是查看器背景。

`ModelViewer.setAlbum(album)` 可在模型已打开时替换封面而不重置相机、拆解位置或玻璃状态。切换时先释放前一张印刷纹理，迟到的图片解码不会覆盖新专辑。`setAlbum(null)` 移除音乐印刷层、恢复原标签可见性以及最近一次 `open()` 的档案标题/编号，以供旧版复用。

## 应保留的通用偏好

| 控件 | 音乐适配建议 |
| --- | --- |
| `data-action="settings"` | 保留设置入口和弹窗行为。 |
| `data-pref="sound"` / `soundVolume` | 保留交互音效独立开关、音量；歌曲音量不能与其绑定。 |
| `data-pref="music"` / `musicVolume` | 原本指场景配乐，应明确改为“氛围配乐”，并与歌曲传输控制分开。新播放器在歌曲开始前将 BGM 淡出，停止/队列结束时恢复；暂停歌曲时保持 BGM 安静。 |
| `data-action="sound-preview"` | 原点击处理器仍存在，当前 `audioSettingsMarkup()` 未渲染对应按钮。如恢复试听按钮，应只试听界面音效，不切换或暂停当前歌曲。 |
| `data-pref="reduced"` | 保留减少动态效果，并同步阵列、文档和查看器。 |
| `quality-preset`、全部 `data-quality` | 保留性能/原始/高/极高预设；精细项包括渲染比例、像素密度、抗锯齿、纹理过滤、透明材质分辨率、阴影、环境遮蔽采样/分辨率、景深。清晰度设置继续同步查看器。 |
| `data-action="fullscreen"` | 浏览器支持时保留全屏开关，不改变播放状态。 |
| 字体许可链接 | 保留真实资源署名和许可证入口。 |
