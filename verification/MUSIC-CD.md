# 简化磨砂 CD 盒

2026-09-15 按用户参考图重建音乐场景模型。保留一条连续侧边及轻磨砂玻璃，不制作内部内容；音乐端暂时屏蔽独立 360°、拆解与重组入口，详情中的拖动旋转保持可用。

- 使用本机 Blender 5.2.2 后台执行 `art/build_music_cd.py`；当前会话没有 Blender MCP 接口。源文件为 `art/music-cd.blend`，浏览器资产为 `public/assets/music-cd.glb`。未覆盖原版档案模型。
- 外形尺寸为 4.3 × 3.7 × 0.26 个场景单位，侧条宽 0.26。前盖、侧条与边框、背壳合并为 3 个材质批次，共 648 个三角形，GLB 约 21 KB。没有光盘、托盘、光学环、螺丝或机械内构。
- 封面位于前盖后面的独立正方形印刷面；画布与几何均为正方形，非正方形封面按 contain 保持比例并留白。不同专辑共用盒体，每张使用自己的纹理。
- 音乐盒保持轻磨砂，详情解密结束后也不变成完全清玻璃。透射模糊限制到投影盒高约 0.3%，避免原有档案玻璃把专辑图案糊掉。
- 局部灯由画面左下方向侧条斜射。方向使用摄像机坐标，目标使用模型世界坐标，随换选与抽取平滑移动。
- 生成脚本同步输出带 GLB 内容摘要的 `src/music-cd-asset.ts`，避免模型更新后命中旧的长期缓存。

验证包含：TypeScript／生产构建、GLB 材质和尺寸检查、音乐循环／封面比例检查，以及浏览器阵列与详情视觉检查。截图中的真实专辑封面不提交到仓库。模型简化降低几何复杂度，但透光与后期处理仍有像素开销，不据此承诺固定帧率。
